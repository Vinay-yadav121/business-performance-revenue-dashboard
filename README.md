# Business Performance & Revenue Analytics Dashboard

A web-based analytics dashboard designed to visualize business performance, lead generation, revenue targets, and quotation activity through interactive charts and KPI cards.

## 🌐 Live Demo

[View the Live Dashboard](https://shiny-swan-886d6b.netlify.app)

## 📊 Features

- **Lead Analytics:** Track new, qualified, converted, and unqualified leads.
- **KPI Cards:** View lead conversion rates, quotations, deals, and invoices.
- **Revenue Tracking:** Visualize revenue targets, achieved amounts, and remaining targets.
- **Lead Funnel:** Explore the progression of leads through different stages.
- **Lead Source Analysis:** Compare lead sources using a visual chart.
- **Quotation Analytics:** Review quotation counts, values, and service-wise details.
- **Interactive Filters:** Filter dashboard data by date range, user, and department.
- **CSV Export:** Export available dashboard data for further analysis.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Data visualization using the charting techniques implemented in the project
